## 二、跨功能一致性结论
- 生成（1 份/多份）→ 新建素材卡；编辑/延长 → 同素材版本；两规则与原版一致
- 计费：图片 0 点；视频 720p 3 点/秒、480p 1 点/秒；与原版 Agent 费用说明一致
- 通知：仅视频生成/编辑/延长产生通知；标题=提示词
- 版本：滑动/点按切换 + 循环，右侧分段指示条与当前项一致

## 三、已知限制（文档化，不做虚假验证）
1. **虚拟形象实拍页**：原版是自定义 App 内相机（人脸/动作引导），原生调起系统相机。需 CameraX/Camera2 管线 + 真人正脸，无法自动验证。
2. **Agent 非费用类回复**：其他建议卡仍是本地兜底文案（无 LLM 后端）。
3. **取消生成**：网关仅极小窗口可取消（queued/running 均 409），原生已优雅提示。
4. **资源库容器**：原版为覆盖 composer 的 sheet，原生为全屏页（功能一致）。
5. 网关模型固定 Grok（原版为 Nano Banana/Veo/Omni），产品差异非 UI 差异。
