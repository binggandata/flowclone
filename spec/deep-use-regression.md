## 一、目标①：三类问题排查与修复

### 1) 游客账号能否生成 ✅
- 退出 → 游客模式（设备账号）→ 新建项目 → 图片生成：成功（任务 succeeded，图片 0 点），卡片正常显示

- 证据：`n335-guest-account.png`、`n336-guest-image-success.png`

### 2) 视频修改失败 ✅（4 个根因 + 1 个计费 bug）
| 根因 | 修复 |
|---|---|
| 上传接口 401 后不刷新 token | upload 增加 401 refresh 重试 |
| 网关内容下载极慢（2–5 分钟），客户端 120s 超时 | 服务端输出缓存 + 直传兜底；客户端重试窗口 10 分钟 |
| 缓存未就绪返回 202，被当成功把 JSON 存成 .mp4 | 仅 200/201 成功；202/404/409/503 重试；媒体头校验 |
| 媒体头校验用 readNBytes（Android 11 崩溃） | 改为手动读头 |
| **480p 实际按 720p 扣 24 点**（提交 quality 写死 720p） | quality 映射修正，ledger 验证 **-8** |
- E2E 验证：480p 8s 视频 → 修改 → 生成成功 → 缓存下载 → 项目「2 项」、详情 0:04/0:08 可播放、原视频保留
- 证据：`n333-video-edit-success.png`、`n334-video-edit-2of2.png`

### 3) 添加动画效果后原图"消失" ✅（页面跳错项目）
- 根因：从素材详情发送时项目解析回退到「项目列表第一个」，完成后跳到别的项目
- 修复：项目解析顺序 = 当前项目 → 当前素材所属项目 → 参考素材 → 附件 → 兜底
- 验证：从图片详情做动画，完成后仍在原项目，原图 + 新视频都在（`n319-animate-same-project.png`）

### 4) 点数不足错误提示 ✅
- 发送前预检：需要点数 > 余额 → 提示「点数不足：本次需要 X 点，当前 Y 点」，不创建素材、不提交请求
- 服务端 402 也映射为友好文案
- 验证：游客 14 点尝试 720p 视频（24 点）→ 被拦截，composer 保留输入（`n338-insufficient-credits.png`）

## 六、已知限制
1. 网关 outputs/content 下载很慢（本次实测 480p 视频约 2 分钟、720p/4MB 约 4 分钟），已用「服务端缓存 + 客户端 10 分钟重试」兜底；网关侧持续变慢时仍可能超时失败
2. 虚拟形象实拍页仍调系统相机（原版为 App 内自定义相机，需 CameraX + 真人正脸）
3. 本地项目数据不随账号隔离（切换账号后本地历史仍可见，属已知设计限制）
4. 资源库/搜索等界面细节与原版仍有极小差异（已记录在 behavior-audit.md）
