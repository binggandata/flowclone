# 内容安全与审核 SOP（草稿）

## 输入侧（提示词）
1. 关键词黑名单 + 第三方审核 API（上线接入，如 OpenAI Moderation / 阿里云内容安全）
2. 命中即拒绝生成并提示用户
3. 记录命中日志，重复违规升级处理

## 输出侧（生成结果）
1. 生成完成后调用图像/视频审核 API
2. 违规内容：隐藏/删除 + 通知用户
3. 严重违规：暂停账号、保留证据

## 举报流程
- App 内素材/智能体输出已有「举报」入口（界面已复刻）
- 服务端接收举报 → 人工复核（SOP：24 小时内处理）→ 处置（删除/警告/封禁）
- 待实现：举报工单表 + 管理后台处理页

## 账号处置
- 警告 → 限制生成 → 封禁（阶梯）
- 记录处置日志（`admin` 接口可查）
