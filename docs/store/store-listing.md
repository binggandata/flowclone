# Play 商店素材要点（草稿）

## 应用名称
FlowClone（学习复刻版）

## 简短说明（80 字内）
AI 图像/视频创作工具：文本生图、图生图、图生视频、连续编辑与数字人。

## 完整说明（要点）
- 文生图 / 图生图（参考图）、文生视频 / 图生视频（首帧）
- 同素材多版本、连续编辑、延长
- AI 视频/图片编辑（修改）
- 项目/集合管理、回收站、搜索
- 智能体对话式创作、资源库
- 云端任务、跨设备历史、生成完成通知
